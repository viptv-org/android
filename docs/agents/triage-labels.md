# Triage labels

Retain the existing project vocabulary; these also match the installed skills.

| Role | Label | Meaning |
| --- | --- | --- |
| Evaluate | `needs-triage` | Scope or action has not been decided |
| Clarify | `needs-info` | A required fact is missing |
| Implement | `ready-for-agent` | Specified and ready for implementation |
| Human work | `ready-for-human` | Requires a human action |
| Declined | `wontfix` | Will not be implemented |

Execution state is separate: `ready`, `in-progress`, `in-review`, `done`.
Sort by resolved blockers first, then ticket number; dependencies are explicit.
