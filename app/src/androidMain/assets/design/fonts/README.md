# Native font assets

Onest 400/500/600/700 from @fontsource/onest 5.3.1; Bricolage Grotesque 700/800 from @fontsource/bricolage-grotesque 5.3.0. Converted from the packaged Latin WOFF2 fonts to lossless TrueType using fontTools 4.65.0 for native Android. Original SIL Open Font License notices accompany the files. These are the same font sources used by tv-web; no network font dependency is required.
