# Lucide TV icons

Exported from lucide-react 0.468.0 (https://lucide.dev), ISC/MIT license in LICENSE. Original rounded SVG paths, 1.8 stroke, 96px PNG raster exports for TV texture compatibility. Primary, secondary and focused colours follow VIPTV tokens. Play uses the original rounded path with solid fill. RotateCcw/RotateCw label backward 10s/forward 30s player actions. SVG sources are retained for reproducibility.

Source selection uses Lucide ListVideo from the same 0.468.0 source and palette.

ROK-042 adds UserRound, Puzzle and Trash2 for native profile, addon and delete
controls. `../../tools/export_design_controls.cjs` retains the reproducible
React/Lucide-to-SVG and node-canvas raster export.
