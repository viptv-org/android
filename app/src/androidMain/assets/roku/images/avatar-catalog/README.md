# Avatar catalog

576 CC0 avatars: 48 deterministic choices in each of 12 DiceBear styles.
Generated with @dicebear/core and @dicebear/styles 10.6.0, rendered with sharp 0.34.3.
Style and artist credits: https://www.dicebear.com/styles/
CC0 dedication: https://creativecommons.org/publicdomain/zero/1.0/

Generate with `node roku/tools/make_avatar_catalog.mjs` after installing the pinned
packages into `artifacts/avatar-tools-20260909`. Every seed is
`viptv-{style}-{choice}`, matching the server's persisted avatar selection.
Only 18 thumbnails are displayed at once. Existing random-seed avatars are retained.
