Build from source: install Node.js and BrighterScript 0.73.1, then from the Roku
source directory run:
npx --yes --package brighterscript@0.73.1 bsc --project bsconfig.json
This validates using the configuration accompanying the source. Then, using a NEW output path, package this plain BrightScript
client with: zip -r viptv-client.zip manifest source components images data
The DSH Roku toolchain alternatively supports roku_check project=roku and
roku_build project=roku with a new ZIP output. Package manifest, source/,
components/, images/ and data/; exclude tests/ and artifacts/. Include this notice
and license in every binary package. Never package the fictional graphite-demo
fixture. Optional private connection configuration is deployment-only and must
be provisioned separately by its owner.
